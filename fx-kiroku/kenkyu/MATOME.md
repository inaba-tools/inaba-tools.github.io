# FX研究のまとめ（最初にこれを読む）

過去データを使う時は、まずこのファイルと下の「結果ファイル」を読む。値段データを取り直す必要はない。

## 保存してあるもの
- `data/trades_YYYY.csv` … ドル円の型（A・A2・B・B2・C など）の毎日の結果（2015〜2026、Dukascopy 1分足から計算済み）
- `data/hiashi_YYYY.csv` … ドル円の日足
- `data/minaoshi_YYYY.csv` / `jousei.csv` / `data/gdelt_YYYY.csv` … 情勢データ（金利差・VIX・発表日・ニュースの明るさ）
- `kekka.json` … 情勢で絞る検証の結果（2015〜2022で決めて2023〜で試す）
- `tsuka/kekka/*.csv` … ほかの通貨（USDJPY・EURUSD・EURJPY・GBPJPY・AUDJPY・AUDUSD）の研究結果。年ごと・候補ごとの回数・勝ち・円
  - `jikan_kekka.csv`（入る時刻×持つ時間×向き）・`jikan_kumi.csv`（買う時刻×売る時刻）・`getsumatsu_kekka.csv`（月末の値決め）・`nagare_kekka.csv`（数週間の流れ）

保存していないもの：5分足の元データ（GitHub Actions の fx-tsuka で作り、30日で消える）。必要になったら `tsuka/go.txt` を書きかえて push すれば作り直せる。

## わかっていること（2026-11-06時点）
- ドル円の型は、過去11年で手数料込みで毎年勝てるものはなかった。情勢で絞っても試す期間で効いたものはほぼない（雇用統計の日を外すのも効果は小さい）
- 月末の値決め：432候補で、決める期間に安定してプラスのものは0
- 数週間の流れ：決める期間で合格2つとも、試す期間でマイナス
- 時刻のくせ：ユーロドルの「深夜1〜2時に買う」くせが一番まとまって強い。今のbotのユーロドル2時買い→9:01売りはこれ
  - 2時買い→13時売り：決める期間8年ともプラス・試す期間4年ともプラス（+18.9万円/1万通貨）→ 2026-11-06からbotで「比較」として記録だけしている
- 本番の値段（GMOコインの実際の買値・売値）で確かめて外したもの：ユーロドル14時売り、型E（五十日7時買い）

## 注意
- 候補を何千個も試しているので、決める期間で合格しても偶然のものが混ざる。理由のあるくせ・まとまって出ているくせを優先する
