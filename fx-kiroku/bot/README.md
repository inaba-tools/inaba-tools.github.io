# FX自動売買（GMOコイン 外国為替FX）

Oracleの無料サーバーで1分ごとに動く。最初は練習モード（本物の注文は出さない）。

- 型A（ドル円）：9時以降に前の平日の高値を上抜けたら買い・安値を下抜けたら売り。損切り50銭（取引所に逆指値を置く）、23:58に決済。
- ユーロドル：火〜金の2:00に買い、9:01に売る（9時ちょうどはスプレッドが1.7pipsに広がるので避ける）。

GMOコインの実際の買値・売値（2023/11〜2026/10・1万通貨・API手数料0.002%込み）での計算：
- 型A：約+26万円（2025年+1.4万円、2026年+2.1万円と最近は弱め）
- ユーロドル2時買い→9:01売り：約+9万円（毎年プラス）
- 外したもの：ユーロドル14時売り（−3.3万円）、型E 五十日7時買い（−12万円・7時のドル円スプレッドが約10銭）

## 入れ方（1回だけ）
サーバーで：
```
curl -sL https://raw.githubusercontent.com/inaba-tools/inaba-tools.github.io/main/fx-kiroku/bot/setup.sh | bash
```
本番にするときは `~/fx-bot/.env` に APIキーを入れて `DRY_RUN=0`。
新しく入るのを止めたいときは `touch ~/fx-bot/STOP`（持っている分の決済は続く）。
