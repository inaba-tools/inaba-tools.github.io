# FX自動売買（GMOコイン 外国為替FX）

Oracleの無料サーバーで1分ごとに動く。最初は練習モード（本物の注文は出さない）。

- 型A（ドル円）：9時以降に前の平日の高値を上抜けたら買い・安値を下抜けたら売り。損切り50銭（取引所に逆指値を置く）、23:58に決済。
- ユーロドル：火〜金の2:00に買い、9:01に売る（9時ちょうどはスプレッドが1.7pipsに広がるので避ける）。
- 比較（記録だけ・注文なし）：型A逆指値方式。12月の判断材料。

GMOコインの実際の買値・売値（2023/11〜2026/10・1万通貨・API手数料0.002%込み）での計算：
- 型A：約+26万円（2025年+1.4万円、2026年+2.1万円と最近は弱め）
- ユーロドル2時買い→9:01売り：約+9万円（毎年プラス）
- 外したもの：ユーロドル14時売り（−3.3万円）、型E 五十日7時買い（−12万円・7時のドル円スプレッドが約10銭）

## 入れ方（1回だけ）
サーバーで：
```
curl -sL https://raw.githubusercontent.com/inaba-tools/inaba-tools.github.io/main/fx-kiroku/bot/setup.sh | bash
```
本番にするときは `~/fx-bot/.env` に APIキーを入れて `DRY_RUN=0`。
新しく入るのを止めたいときは `touch ~/fx-bot/STOP`（持っている分の決済は続く）。

## 健康診断と自動ストップ（2026-11-05 追加）
- 毎朝8:05に健康診断：時計のずれ・空き容量・GMOにつながるか・回収よけが動いているか・（本番）APIキーで口座が見られるか・証拠金維持率。問題があればメール（【要確認】）。
- 損の上限：1日 −1.5万円、直近30日 −5万円（`.env` の `LIMIT_DAY` / `LIMIT_30D` で変更）。本番は超えたら STOP（新しく入らない・持っている分の決済は続く）、練習はメールだけ。
- 15分続けてエラー：本番は STOP、練習はメールだけ。
- 再開するとき：`rm ~/fx-bot/STOP`

## Oracleの回収よけ
Oracleは無料サーバーが7日間「CPU・ネットワークとも使用20%未満」だと止めることがある（2026年の決まり）。
`bot.py busy` がCPUを約3割、いちばん低い優先度で使い続けて、これを避ける（cronで1分ごとに「動いていなければ起動」）。
止められても、Oracleの画面で「起動」を押せば中身はそのまま戻る（1時間ごとの見張りがメールで知らせる）。

## 候補の型を自動で育てる（2026-11-06 追加）
- `bot.py kouho`（本番botとは別のプロセス、1分ごと）が、研究で良かった7つの候補を「記録だけ」で並走させる → `kouho.csv`
- 毎朝8:10に判定 → `kouho.json`（live＝本番に入れた候補、off＝入れ替えで休ませている今の型、retired＝外した候補）
- 合格：記録60回以上・合計+6,000円以上・直近30回もプラス（12/24〜1/3は数えない）
- 同じ通貨で持つ時間が重なる型は1つまで（今の型も含む）。重なる時は同じ期間で1万円以上上回った時だけ入れ替え
- 本番は全部で4つまで。証拠金の空きが10万円未満なら入らない。損は「損の上限」に数える
- 本番で30回以上・合計マイナス・記録より1回100円以上悪ければ、持っている分を決済してから外す（外した候補は戻さない）
