よくある質問

使い方
「まとめ日」って何？
申し込むのは毎週火曜の夜だけです。
その夜に申し込めるIPOと分売を、証券会社ごとにまとめて申し込みます。
分売だけの夜は、楽天だけ（ログイン1回）にしています。
火曜に間に合わないものは見送りです。
ただし評価S・Aの人気IPOだけは、締切の前の夜にお知らせします。
IPOと分売を、証券会社ごとに1回ログインしてまとめて申し込む日です。
分売の申込が始まる夜（前の営業日の17:15〜）があれば、その夜に申し込めるIPOも一緒にまとめます。
分売が無いときは、IPOの締切の前の夜にまとめます。
申し込んだら何をする？
「今日」の一覧で、申し込んだ証券会社の丸をタップするだけです。
全部の会社が済むと、自動で「申込済み」になります。
結果が出たら？
「当たった」か「外れた」を押すだけです。
当たったら「今日」に売る日が出ます。
売ったら、売った値段を入れると「実績」に入ります。
状態はどう変わる？
申込前 → 申込済み → 当選 → 終了の順に、自動で進みます。
申込期間が終わると、申し込まなかったものは「終了」に入ります。
IPO
IPOって何？
これから新しく上場する会社の株を、上場の前に抽選で買えるしくみです。
人気の会社は上場した日に値段が上がることが多いので、当たったら上場日の朝に売るだけで利益になりやすいです。
外れたら、お金はそのまま口座に残ります。
予想利益はどう計算している？
（初値予想 − 公開価格）× 株数 です。
公開価格が決まるまでは仮条件の上限、仮条件もまだなら想定価格で計算しています。
初値予想は96ut.comの数字です。
予想なので外れることもあります。
どの会社で申し込むかはどう決めている？
SBI証券はポイント用：どのIPOも100株だけ申し込み、外れるたびにポイントを貯めます。
ほかの会社：評価がS・A・Bで予想利益がプラスのときだけ、100株ずつ申し込みます。
評価C以下や予想がマイナスのときは、SBIだけにします。
お金はいつ必要？
証券会社ごとに違います（目安）。
楽天：抽選日の18時まで
SBI：抽選日まで（同じお金でほかのIPOにも申し込める）
松井・野村・DMM株：当たってから
三菱UFJ eスマート：購入申込のとき
「今日」の「入れておくお金」に、会社ごとの金額と期限が出ます。
当選しても買わなくていい？
いいです。
購入申込の期間に「購入」を押さなければ、買わなかった扱いになります。
公募割れしそうなときは、あえて買わないのも作戦です。
アプリでは「買わなかった」を押してください。
評価 S・A・B・C・D って？
予想サイトの管理人がつけた人気の目安です。
S・A：かなり人気
B：まあまあ人気
C：少し上がるかも
D：公募割れの心配あり
SBIのポイントって？
SBI証券でIPOに外れるたびに1ポイント貯まります。
ふだんは使わずに貯めて、評価S・Aの人気IPOで一気に使うのが基本です。
アプリの数字は、落選を記録した数から数えた目安です（設定 → 証券口座 で直せます）。
分売
立会外分売って？
すでに上場している株を、大株主などが前の日の終値より少し安く売り出す日があります。
当たると安く買えて、当日の朝9時から売れます。
分売で損することはある？
あります。
当日の始値が分売の値段より下がると損になります。
「実績」の「分売の過去の実績」で、始値で売ったら何件が得だったかを確認できます。
アプリ
データはどこから？
IPOと分売の日程は楽天証券の公開ページ、初値予想は96ut.com、株価はYahoo!ファイナンスから、3時間ごとに自動で取り込んでいます。
記録はどこに保存される？
この端末と、ログインしたGoogleアカウントに保存されます。
別の端末でも、同じアカウントでログインすれば同じ記録が出ます。
通知が届かないときは？
iPhone：Safariで「ホーム画面に追加」したアプリから開き、設定 → 通知 でオンにしてください。
iPhoneの設定 → 通知 → KABU DROP が許可されているかも確認してください。
Android：Chromeで開いて、設定 → 通知 でオンにしてください。
