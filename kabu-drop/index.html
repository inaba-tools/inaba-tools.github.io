Q&A

💧 IPO
IPOって何？
これから新しく上場する会社の株を、上場の前に抽選で買えるしくみです。人気の会社は上場した日に値段が上がる事が多いので、当たったら上場日の朝に売るだけで利益になりやすいです。ハズレたら、お金はそのまま口座に残ります。
値段はいつ決まるの？（仮条件・公開価格）
値段は2段階で決まります。
①仮条件：仮の値段の幅（例：550〜570円）。申込が始まる少し前に決まります。
②申込（ブックビルディング）：この期間に各証券会社で申し込みます。
③公開価格：本決まりの値段。抽選の日に決まり、ほとんどは仮条件の一番高い値段になります。
カードの「①②③」の丸で、今どこまで決まったかが分かります。
お金はいつ必要？
お金が要る時期は証券会社ごとに違います（目安）。
・楽天：抽選日の18時まで
・SBI：抽選日まで（同じお金で他のIPOにも申し込める）
・松井・野村：当たってから
・マネックス・SMBC日興：申込の時（抽選が終わるまで使えない）
・みずほ・大和・岡三・東海東京：申込の時
金額は 株数 × 公開価格（普通100株）。例：公開価格 1,620円なら 162,000円。ハズレたら、お金はそのまま使えます。
カードの「おすすめの申込」に、会社ごとの金額と時期が出ます。条件は変わることがあるので、申し込む時に各社の画面でも確認してね。
抽選に外れたら、お金はいつ戻る？
安心してください。お金は口座から出ていきません。抽選のあいだ「使えない（ロック）」になる会社があるだけで、外れが決まったら、また使えるようになります（目安）。
・楽天：抽選日の18時にロック → 外れたら、結果が出ればすぐ使える
・SBI：外れたら、そもそもロックされない（当たった時だけ）
・松井・野村：当たってから入金するので、外れても何も動かない
・マネックス・SMBC日興：申込の時からロック → 外れたら、結果が出れば使える
・みずほ・大和・岡三・東海東京：申込の時に入金。外れたら、そのまま使える
ロックがとけたお金は、他のIPOなどにそのまま使えます。銀行に戻したい時は、各社のアプリから出金してね。
細かいタイミングは会社やIPOで違うことがあるので、各社の画面でも確認してね。
当選しても買わなくて良いの？
いいです。楽天証券では、当選しても購入申込期間に「購入」を押さなければ、買わなかった扱いになります（自分から「辞退」もできます）。楽天の案内には、辞退した時のペナルティ（次から当たりにくくなる等）は書かれていません。
ただし証券会社によっては、辞退すると次の抽選で不利になるところもあるので、口座を増やす時は確認しましょう。初値予想が公開価格より低い（公募割れのおそれ）時は、あえて買わないのも作戦です。
「👍 良さそう」「✋ 見送り」って？
カードに出る買うかどうかの目安です。
👍 申し込んで良さそう／買って良さそう：評価がDではなく、予想利益がプラス
✋ 見送りが良さそう：評価がD、または予想利益が0円以下
2026年のIPO 35件で試すと、全部買うと公募割れ12件（損の合計−131,400円）でしたが、このルールなら25件中4件（−70,100円）に減り、儲けの合計は+887,700円（100株ずつ・全部当選した場合）でした。
見送る時は、カードを ← 左にスワイプすると一番下の「見送ったIPO」に入ります。
当選しても買わなくて良いなら、絶対得する？
絶対ではありません。「買うか決める日（購入申込期間）」は上場日より前なので、本当の初値を見てから決めることはできません。決める時に使えるのは初値予想だけです。
2026年のIPO 35件のうち12件が公募割れ（初値が公開価格より下）でした。中には予想がプラスだったのに外れたものもあり、例：公開価格 4,040円・予想 5,180円 → 初値 3,760円（100株で−28,000円）。
それでも全体の真ん中は100株で+14,000円くらいで、平均すると得の方が多いです。「評価が低い・公募割れのおそれ」が出ているものは買わない、を守ると損しにくくなります。
公開価格は予想できるの？
かなり予想できます。
①上場が決まった時に想定価格（会社が出す目安）が出ます
②申込の少し前に仮条件（例：550〜570円）が決まります
③人気のIPOは、ほとんどの場合仮条件の一番高い値段で公開価格が決まります
そのためアプリでは、公開価格が決まるまでは「仮条件の上限」、仮条件もまだなら「想定価格」を目安として出し、予想利益もその値段で計算しています。
初値予想って何？
上場して最初につく値段（初値）の予想です。予想サイト（96ut.com）の数字を出しています。
「直前予想」＝上場日の少し前に出るプロの予想（一番当たりやすい）、「申込開始時の予想」＝申込が始まる時（ブックビルディング開始時）に出る予想、「みんなの予想」＝読者の投票の平均。
「100株で +〇円」は、公開価格で買って初値で売ったら、という目安です。あくまで予想なので外れることもあります。
評価 S・A・B・C・D って？
予想サイトの管理人がつけた人気の目安です。
S・A：かなり人気。大きく上がりそう
B：まあまあ人気。上がりそう
C：少し上がるかも
D：公募割れ（買った値段より下がる）の心配あり
Dや「公募割れのおそれ」が出ているものは、申し込むか慎重に考えましょう。
「人気になりやすい市場」って？
上場する場所（市場）による傾向です。
グロース：小さく成長中の会社が多く、株の数も少ないので人気になって上がりやすい
プライム：大きい会社が多く、上がりにくめ
地方（名証・福証・札証）・PRO市場：買う人が少なく、注意が必要
REIT（〜投資法人）：不動産の投資信託。値上がりしにくい
あくまで傾向なので、初値予想とあわせて見てください。
分売の「👍 良さそう」「✋ 見送り」って？
分売がどの市場の株かで決めている目安です。
👍 申し込んで良さそう：東証（プライム・スタンダード・グロース）
✋ 見送りが良さそう：地方市場（名証・福証・札証）
2026年に楽天で扱った分売（100株・始値で売った場合）では、東証は26件中22件が得（平均 約+3,000円、一番の損 −1,600円）、地方は7件中2件だけ（平均 −2,042円、一番の損 −14,300円）でした。
東証でも小さく損することはあります。見送る時は ← 左にスワイプ。
公募割れって？
初値が公開価格より下になってしまうことです。当たっても売ると損になります。初値予想が公開価格以下の時は、カードに「公募割れのおそれ」と赤で出ます。
当選したら何をすれば良い？
①購入申込期間に楽天証券で「購入」を押す（押さないと当選が無効になります）
②上場日の朝に「成行」で売る（初値で売れます）
③アプリで「売った」を押して、売った値段を入れると、儲けが記録されます。
IPOの当選率はどれくらい？
公表はされていませんが、人気のIPOだとネット抽選は0.01〜0.1％くらい（数千〜数万人に1人）と言われます。普通の人気なら0.1〜数％、不人気なものはもっと当たりやすい（そのかわり公募割れも多い）です。
楽天1口座だけだと、年に1回当たるかも微妙。だから証券口座を複数持つのが基本です。口座の数だけ抽選に参加できます（同じ会社に2つはNG）。
証券口座を増やすデメリットは？
大きなデメリットはありませんが、気をつけることはあります。
・管理が増える：ログインIDやパスワードが増える。パスワード管理アプリでまとめると安心
・乗っ取りに注意：証券口座をねらった不正ログインが増えているので、二段階認証は必ずオンに
・お金が分かれる：申込の時点でお金が必要な会社だと、口座ごとにお金を入れておく必要がある
・NISAは1社だけ：NISA口座は同じ年に1つの会社でしか使えない。新しい会社ではNISAを申し込まず、普通の「特定口座（源泉徴収あり）」にすれば、今のNISAはそのまま
・メールやお知らせが増える：いらないものは設定で止められる
口座を作るのも持っておくのも、主なネット証券・大手はお金がかかりません。
どの会社で何株申し込めばいい？
このアプリのやり方はこうです。
①SBI証券＝ポイント用：どのIPOも100株だけ、ポイントは使わずに申し込む。外れる度に1ポイント貯まります
②他の会社＝くじを増やす用：評価がS・A・Bで予想利益がプラスの時だけ、100株ずつ申し込む。1人1回の抽選の会社が多いので、100株で十分です
③評価C以下・予想利益がマイナス：SBIだけ（ポイントのため）。当たっても、公募割れしそうなら買わない（辞退する）こともできます
カードの「おすすめの申込」に、会社ごとの株数・金額・お金が要る時期が出ます。使う証券会社は、設定 → 証券口座 で選べます。
SBIのポイント（IPOチャレンジポイント）って？
SBI証券でIPOに外れる度に1ポイント貯まります（何株申し込んでも、1つのIPOで1ポイント）。
申込の時に「ポイントを使う」にすると、ポイントが多い人から優先して当たる枠があります。
・使って外れたら：ポイントは戻って、さらに1ポイント増える
・使って当たったら：使ったポイントはなくなる（辞退しても戻らない）
少しだけ使うと、普通の抽選で当たった時にポイントがむだになるので、ふだんは使わずに貯めて、評価S・Aの人気IPOで一気に使うのが基本です。
当たるのに必要なポイントは公表されていませんが、個人サイトの調べ（2023年）では、評価Sで500〜650P、Aで400〜550P、Bで200〜400Pくらいと言われます。アプリの「SBIのポイント」は、落選を記録したIPOでSBIに申し込んでいた数から数えた目安です（設定 → 証券口座 で直せます）。
「予定」って？
まだ申込が始まっていないIPO・分売です。申込が始まると、自動で「申込できる」に移ります。
予定のうちから「おすすめの申込」で、どの会社にいくら必要かを確認して、お金や口座の準備をしておけます。見送るなら ← 左にスワイプ。
🛍 分売
立会外分売（たちあいがいぶんばい）って？
すでに上場している株を、大株主などが前の日の終値より少し安くまとめて売り出す日があります。申し込んで当たると安い値段で買えて、当日の朝9時からすぐ売れます。例：前の日2,000円の株が1,940円 → 100株で6,000円安く買える。
いつ申し込むの？結果は？
申込は実施日の前の営業日の夕方（17:15ごろ）〜当日の朝8:20。楽天は「国内株式 → 注文 → 立会外分売」から。結果は当日の朝に分かります。値段と日にちは、実施の前の日の夕方に決まります。
分売で損することはある？
あります。当日の始値が分売の値段より下がると、売った時に損になります。分売タブの下にある「これまでの実績」で、始値で売ったら何件が得だったか・平均いくらかを確認してから申し込むと安心です。
⚙ アプリ
データはどこから？いつ更新される？
IPOと分売の日程は楽天証券の公開ページ、初値予想は96ut.com、分売の株価はYahoo!ファイナンスから、3時間ごとに自動で取り込んでいます。
記録はどこに保存される？
申込・当選の記録は、この端末と、Googleスプレッドシート「決算チェッカー」のログに保存されます。別の端末で開いても同じ記録が出ます。
通知が届かない時は？
iPhone：①Safariで「ホーム画面に追加」したアプリから開く必要があります（iOS 16.4以上） ②このアプリの設定 → 通知 でオンになっているか確認 ③iPhoneの設定 → 通知 → KABU DROP が許可されているか確認。
Android：①Chromeで開く（ホーム画面に追加しなくてもOK。追加するとアプリのように使えます） ②このアプリの設定 → 通知 でオンになっているか確認 ③Androidの設定 → アプリ → Chrome（またはKABU DROP）→ 通知 が許可されているか確認。省電力モードだと遅れることがあります。
通知は朝・夕方などに1日数回まとめて送るので、少し遅れることがあります。

  • 0申込は無料。手数料も掛かりません

  • +当たれば、数万円の利益になることも
  • ✓だから、良さそうなIPOには全部申し込むのが基本
